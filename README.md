# To-Do List Android App

## Overview
A task management app built with Kotlin, Jetpack Compose, and Android SDK for the CIS4034-N Mobile App Development module.

## Setup Instructions
1. Clone the repository: `git clone https://github.com/FidaHussain110/Todo-List.git`
2. Open in Android Studio (Arctic Fox or later).
3. Sync Gradle to download dependencies.
4. Run on an emulator or device with API 34.
5. Ensure location services are enabled for geofencing.

## Dependencies
- Jetpack Compose
- Room
- Retrofit
- Google Maps
- OkHttp

## Development Process
- **Version Control**: Git with GitHub repository. See `Documentation/git_log.txt` for commit history.
- **Project Management**: Trello board with sprint tasks. See `Documentation/sprint1.png` to `sprint5.png` for evidence.

## Notes

- Internet access is needed for API and email sharing.
